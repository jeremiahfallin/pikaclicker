## 2024-04-15 - Explicit Confirmation for Destructive UI Actions
**Learning:** For destructive actions (like releasing an item or Pokémon) that require a secondary click to confirm, relying solely on a visual cue (like changing the button color to red) without updating the button text is an accessibility failure and creates a confusing UX. Screen reader users and general users might not understand that the action state has changed from "Intent to release" to "Confirm release".
**Action:** When implementing secondary-click confirmation flows, always update the visible text to explicitly state the action being confirmed (e.g., from "Release" to "Confirm") and dynamically update the `aria-label` to clearly articulate the action to assistive technologies (e.g., "Confirm release of [Item]").
