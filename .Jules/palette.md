## 2025-01-28 - Explicit Confirmation on Destructive Actions\n**Learning:** Destructive actions (like releasing a Pokémon) that use a two-step confirmation purely by changing the button color (e.g., from gray to red) create a significant accessibility and usability issue. Screen reader users won't know the button's function has changed to a confirmation step, and visually impaired or colorblind users might miss the color cue entirely.\n**Action:** When implementing secondary-click confirmations for destructive actions, always explicitly update the visible button text (e.g., from "Release" to "Confirm release") and the `aria-label` (e.g., from "Release [Item]" to "Confirm release of [Item]") to ensure the action is clear and accessible.
