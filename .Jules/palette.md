## 2024-03-24 - Clear Disabled States for Dependent Actions\n**Learning:** In a UI where actions (like using an item) depend on prior selections (like selecting a Pokémon), allowing the user to click the item with no visual feedback creates a feeling of unresponsiveness and broken functionality.\n**Action:** Always wrap dependent action buttons in tooltips explaining the missing prerequisite, and apply a visual disabled state (`opacity` and `cursor`) to guide the user.
