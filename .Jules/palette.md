## 2024-03-20 - Explicit Confirmation Actions
**Learning:** For destructive UI actions (like releasing an item or Pokémon), relying solely on a secondary click (or color change) for confirmation is insufficient for accessibility and clarity.
**Action:** Always update the visible text and `aria-label` of the confirmation button to explicitly state the action being confirmed (e.g., 'Confirm release of [Item]') to ensure clarity and accessibility.
